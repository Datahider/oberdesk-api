# Dashboard API v0

`GET /v0/getDashboardData` возвращает существующий JSON-контракт дашборда:

- `params` — параметры запроса;
- `statuses` — справочник статусов;
- `agents` — агенты выбранных групп и их статистика;
- `tickets` — актуальные тикеты выбранных групп, назначенные агенты и учтённое время.

## Загрузка данных

Один HTTP-запрос выполняет ровно три пакетные выборки независимо от числа агентов и тикетов:

1. агенты вместе с дневной и месячной статистикой;
2. актуальные тикеты;
3. агенты и учтённое время сразу для всех актуальных тикетов.

SQL-запросы внутри циклов по агентам или тикетам запрещены. Временные таблицы для построения ответа не используются.

Для пакетных выборок обязательны индексы:

- `timer_events(object, timer)`;
- `timer_events(timer, start_time)`;
- `timer_events(end_time, comment, timer)`;
- `timers(subject, id)`;
- `user_chat_role(chat_id, role, user_id)`.

Индексы однократно создаются командой `php bin/add-dashboard-indexes.php`. Повторный запуск должен завершаться ошибкой, а не скрывать несоответствие схемы.

Для каждого тикета поле `agents` содержит только его агентов. Поля `seconds_total` и `seconds_today` равны сумме одноимённых значений его агентов; при отсутствии агентов возвращаются пустой массив и нули.
