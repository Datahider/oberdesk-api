# AGENTS.md

Наследует `/home/web/AGENTS.md`.

## Проект

- `v0` — старый API, сохраняется без несовместимых изменений.
- `v1` — REST API для Oberdesk mini-app и интеграций.
- Боевой `v1/etc/config.php` содержит секреты и никогда не входит в Git.
- Зависимости `vendor` устанавливаются Composer и никогда не входят в Git.
- Работа с MariaDB выполняется через `losthost/db`.
- Запросы через `DB::prepare()` без согласования запрещены.
